# Nexus Sovereign Agency — تشغيل الوكلاء المتواصل 24/7/365

يعمل هذا النظام كـ **محرك استخباراتي وتسويقي متواصل على مدار الساعة وطوال 365 يوماً في السنة** على سيرفرات GitHub Actions السحابية، بدون الحاجة لأن يكون جهازك مفتوحاً أو متصلاً بالإنترنت إطلاقاً.

## نبضات التشغيل المتواصل على مدار اليوم (Continuous Daily Cycles):
1. **دورة الفجر والرادار الصباحي (06:00 - 11:00 بتوقيت القاهرة/الرياض):**
   * كشف السوق، رصد العيادات وشركات الديكور والمطاعم المستهدفة في الرياض ودبي.
   * فحص ثغرات الفيديو، بطء المواقع، وتسريب المواعيد.
2. **دورة متابعة التواصل والردود (11:00 - 15:00):**
   * صياغة نصوص الإقناع المخصصة للواتساب والانستقرام.
   * تجهيز مسودات الردود على العملاء لاعتماد المدير.
3. **دورة تطوير العينات وتجهيز التيم (15:00 - 19:00):**
   * تنفيذ النماذج البصرية وصفحات الهبوط السريعة عبر الوكيل الذكي (`DESIGN-06`).
4. **دورة النبض المسائي والاستعداد (19:00 - 05:00):**
   * رصد إعلانات المنافسين ومؤشرات التفاعل الليلي، وتجهيز قائمة أولويات الصباح.

## حماية المدير والسيادة الكاملة:
- **لا إرسال ولا نشر تلقائي:** لن تخرج أي رسالة، ولن يُنشر أي تصميم إلا بعد اعتمادك المباشر في لوحة التحكم.
- **التسعير بيد المدير:** خانة السعر يحددها مدير الوكالة لكل صفقة على حدة.
